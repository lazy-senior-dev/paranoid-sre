# Contributing

This persona is being built in the open. Until the first release, the most useful contribution is an incident: a change that shipped, paged someone, and would have been caught by one of the ten questions in `rules/paranoid-sre.md`. Open an issue with the change (anonymised), what paged, and which question should have caught it. It becomes a benchmark case.

Rules of the house are the same as grumpy-reviewer: plain conventional commits, no emoji, Node 20 or newer, no runtime dependencies, and commit as yourself.
